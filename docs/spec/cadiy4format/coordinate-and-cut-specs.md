## 1. 座標系の特定（右手系 vs 左手系）

### 結論: caDYI3D は完全な「右手系 (Right-handed System)」

caDYI3D は、3Dグラフィックス標準（OpenGL, Three.js, Blender 等）と同様の **右手系（Y-up, +Z 正面手前）** を採用しています。

```
          +Y (上 / Up)
           |
           |   +Z (正面手前 / Front)
           |  /
           | /
           |/
 (左) -----+-----> +X (右 / Right)
```

### 1.1 数学的・幾何学的証明

1. **基本基底ベクトルと外積 (Cross Product)**:
   - $X$ 軸単位ベクトル: $\vec{e}_x = (1, 0, 0)$ （右方向）
   - $Y$ 軸単位ベクトル: $\vec{e}_y = (0, 1, 0)$ （上方向、床面は $y = 0$）
   - $Z$ 軸単位ベクトル: $\vec{e}_z = (0, 0, 1)$ （正面手前方向）

   右手系の定義式:
   $$\vec{e}_x \times \vec{e}_y = (1, 0, 0) \times (0, 1, 0) = (0, 0, 1) = \vec{e}_z$$

   外積の結果が正の $Z$ 軸ベクトルと一致するため、数学的に右手系であることが確定します（左手系であれば外積は $-\vec{e}_z$ となり奥方向を指します）。

2. **回転の向き（右ねじの法則）**:
   MCP `update_objects` で部材に $Y$ 軸周りの正の回転角 $+90^\circ$（`rotationDeg: { x: 0, y: 90, z: 0 }`）を適用した際の四元数およびベクトル変換を検証：
   - 内部生成された四元数: $q = (0, 0.7071068, 0, 0.7071068) = (0, \sin(45^\circ), 0, \cos(45^\circ))$
   - ローカル $+Z$ ベクトル $(0, 0, 1)$ はワールド $+X$ ベクトル $(1, 0, 0)$ へ回転。
   - ローカル $+X$ ベクトル $(1, 0, 0)$ はワールド $-Z$ ベクトル $(0, 0, -1)$ へ回転。
   - 上（$+Y$）から見下ろしたとき、正の角度による回転は**反時計回り（CCW: Counter-Clockwise）**であり、右手の親指を $+Y$ に向けた際の指の巻き込み方向（右ねじの進む向き）と完全に一致します。

### 1.2 ビューポートおよび UI での検証（MCP操作と画面キャプチャ）

MCP 経由で各軸上に配置した直方体パーツと、caDYI3D 画面のキャプチャ（`capture_view`）を照合：
- **赤軸（グリッド上の赤線）**: $+X$ 方向（右方向）
- **青軸（グリッド上の青線）**: $+Z$ 方向（手前方向）
- **垂直方向**: $+Y$ 方向（上方向）
- カメラ位置: `camera.position = { x: -6.66, y: 7.8, z: 10.7 }` から `target = { x: 1.14, y: 1.09, z: 0.3 }` を見下ろす視点で、RGB（赤・緑・青）が XYZ に対応して表示されます。

## 2. 角度カット (`cutAngles`) の仕様特定

木材の木口（端面）や板材の端縁に対して適用されるマイター角・ベベル角・傾斜カットの仕様です。
フォーマット上、**8要素の浮動小数点配列（度数法 [deg]）** として定義されています。

```json
"cutAngles": [c0, c1, c2, c3, c4, c5, c6, c7]
```

### 2.1 角材 (`lumber`) における 8要素の構造

角材の長さ方向はローカル $Z$ 軸です（両端面は $-Z$ 端面 と $+Z$ 端面）。

| インデックス | 端面 | 回転軸 / 傾斜面 | 呼称 / 加工内容 |
| :---: | :---: | :---: | :--- |
| `[0]` | **始端 (Start / -Z側)** | ローカル $Y$ 軸周り | 幅方向（$X$ 軸方向）のマイターカット角（水平留め継ぎ） |
| `[1]` | **始端 (Start / -Z側)** | ローカル $X$ 軸周り | 厚み方向（$Y$ 軸方向）のベベルカット角（傾斜・勾配カット） |
| `[2]` | **終端 (End / +Z側)** | ローカル $Y$ 軸周り | 幅方向（$X$ 軸方向）のマイターカット角（水平留め継ぎ） |
| `[3]` | **終端 (End / +Z側)** | ローカル $X$ 軸周り | 厚み方向（$Y$ 軸方向）のベベルカット角（傾斜・勾配カット） |
| `[4..7]` | 通常 `0` | - | （板材用端縁カット予約領域） |

#### 実データによる検証例（`DopaGardenHouse.cadiy` より）:
- **屋根の垂木 (Rafter, 45度勾配)**:
  - `Size`: `{ x: 0.089, y: 0.038, z: 1.205 }` （SPF 2x4材）
  - `cutAngles`: `[0, 45, 0, -45, 0, 0, 0, 0]`
  - `[1] = 45°`: 屋根の棟木（頂点側、$-Z$ 端面）に鉛直に接合するための45度ベベルカット。
  - `[3] = -45°`: 軒桁（下端側、$+$Z 端面）に水平・鉛直に接合するための-45度ベベルカット。
- **方杖・筋交い (Brace, 45度留め継ぎ)**:
  - `Size`: `{ x: 0.03, y: 0.03, z: 0.523 }` （杉角材）
  - `cutAngles`: `[-45, 0, -45, 0, 0, 0, 0, 0]` または `[45, 0, 45, 0, 0, 0, 0, 0]`
  - `[0]` と `[2]`: 柱と梁の内角45度にぴったり納めるための両端留め継ぎカット。

### 2.2 板材 (`board`) における 8要素の構造

板材（合板等）では、外周4辺（短辺・長辺）の傾斜・面取りカット角として `[4..7]` が主に使用されます。

| インデックス | 対象端縁 | 呼称 / 用途 |
| :---: | :---: | :--- |
| `[4]` | 短辺 1 (幅端面 / $X-$) | 妻壁上端等の傾斜カット角（例: 切妻屋根勾配 30.9°） |
| `[5]` | 短辺 2 (幅端面 / $X+$) | 短辺側の傾斜カット角 |
| `[6]` | 長辺 1 (長手端面 / $Z-$) | 屋根野地板・天井板の軒先勾配カット角（例: 屋根勾配 12°） |
| `[7]` | 長辺 2 (長手端面 / $Z+$) | 長辺側の傾斜カット角 |

## 3. 形状加工 (`edgeCuts`) の仕様特定

板材や角材の辺（エッジ）に対して適用されるコーナー斜めカット（三角形面取り）および角丸（フィレット）加工の仕様です。

```json
{
  "edgeIndex": 4,
  "mode": "cut",
  "faceADist": 0.6123,
  "faceBDist": 0.1302,
  "radius": 0.05
}
```

### 3.1 12本のエッジインデックス (`edgeIndex: 0..11`) の配置

直方体バウンディングボックスの 12 辺は、下底面・垂直側面・上底面の 3 グループに体系化されています。

```
        V7 (奥左上) +-------[10]-------+ V6 (奥右上)
                   /|                 /|
                 [11] |              [9] |
                 /  [7]             /  [6]
      V4 (手前左上) +-------[8]--------+ V5 (手前右上)
                |   |              |   |
                |   |              |   |
                |  V3 (奥左下) +----|--[2]-------+ V2 (奥右下)
               [5] /              [4] /
                | [3]              | [1]
                |/                 |/
      V0 (手前左下) +-------[0]--------+ V1 (手前右下)
```

| エッジ番号 (`edgeIndex`) | 方向 | 位置 / 端点座標 | 板材における役割 |
| :---: | :---: | :---: | :--- |
| **`0`** | $X$ 軸平行 | 下面手前 ($Y-, Z+$) | 下面・手前長辺のエッジ |
| **`1`** | $Z$ 軸平行 | 下面右 ($Y-, X+$) | 下面・右短辺のエッジ |
| **`2`** | $X$ 軸平行 | 下面奥 ($Y-, Z-$) | 下面・奥長辺のエッジ |
| **`3`** | $Z$ 軸平行 | 下面左 ($Y-, X-$) | 下面・左短辺のエッジ |
| **`4`** | **$Y$ 軸平行 (垂直)** | **手前右 ($X+, Z+$)** | **板材の「手前右角（コーナー4）」の斜めカット / R加工** |
| **`5`** | **$Y$ 軸平行 (垂直)** | **奥右 ($X+, Z-$)** | **板材の「奥右角（コーナー5）」の斜めカット / R加工** |
| **`6`** | **$Y$ 軸平行 (垂直)** | **手前左 ($X-, Z+$)** | **板材の「手前左角（コーナー6）」の斜めカット / 側板上端斜めカット** |
| **`7`** | **$Y$ 軸平行 (垂直)** | **奥左 ($X-, Z-$)** | **板材の「奥左角（コーナー7）」の斜めカット / R加工** |

> **エッジ番号のビット構造**:
> 垂直エッジ 4..7 は、軸の符号によってビットフラグとして規則的に割り振られています：
> $$\text{edgeIndex} = 4 + (x < 0 ? 2 : 0) + (z < 0 ? 1 : 0)$$
> - $X > 0, Z > 0 \implies 4$ (手前右)
> - $X > 0, Z < 0 \implies 5$ (奥右)
> - $X < 0, Z > 0 \implies 6$ (手前左)
> - $X < 0, Z < 0 \implies 7$ (奥左)
| **`8`** | $X$ 軸平行 | 上面手前 ($Y+, Z+$) | 上面・手前長辺のエッジ |
| **`9`** | $Z$ 軸平行 | 上面右 ($Y+, X+$) | 上面・右短辺のエッジ |
| **`10`** | $X$ 軸平行 | 上面奥 ($Y+, Z-$) | 上面・奥長辺のエッジ |
| **`11`** | $Z$ 軸平行 | 上面左 ($Y+, X-$) | 上面・左短辺のエッジ |

### 3.2 切削距離パラメータ (`faceADist`, `faceBDist`)

板材（厚み $Y$、幅 $X$、長さ $Z$）のコーナー垂直エッジ（4..7）をカットする場合：
- **`faceADist`**: 隣接する面A（**ローカル $X$ 軸 / 幅方向**）に沿った切り落とし距離 [m]。
- **`faceBDist`**: 隣接する面B（**ローカル $Z$ 軸 / 長さ方向**）に沿った切り落とし距離 [m]。

#### 実データでの完全一致検証（`007.cadiy4` / `002.cadiy4`）:
1. `007.cadiy4` の部材 7 (`斜めカット02`):
   - `size`: `{ x: 0.6123272, y: 0.012, z: 0.5039161 }`
   - `edgeCuts`: `[{ "edgeIndex": 4, "faceADist": 0.6123272, "faceBDist": 0.130154 }]`
   - 結果: `faceADist` が部材幅 `size.x`（0.6123272m）と完全に一致。手前右角から幅全体にわたる三角斜め切り落とし。
2. `007.cadiy4` の部材 32:
   - `size`: `{ x: 0.7547637, y: 0.012, z: 1.421984 }`
   - `edgeCuts`: `[{ "edgeIndex": 7, "faceADist": 0.302252, "faceBDist": 1.421984 }]`
   - 結果: `faceBDist` が部材長さ `size.z`（1.421984m）と完全に一致。奥左角から長さ全体にわたる三角斜め切り落とし。
