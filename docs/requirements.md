# caDIY3D Web 3Dモデルビューア 要件定義書

- **文書バージョン**: 2.1.0
- **改訂日**: 2026-11-19
- **対象システム**: caDIY3D Web Viewer
- **作成・改訂理由**: 
  - レイヤー一覧におけるサブフォルダを含むn段階層ツリー構造表示への対応
  - ファイル読み込み後の初期表示時におけるレイヤーツリー折りたたみ（全閉状態）の定義
  - 初期表示時における非表示レイヤー・オブジェクトの描画抑止（非表示制御）の厳格化
  - 大規模モデル（`testdata/006.cadiy4`等）に対する軽量切り出しテスト検証方針の明記

## 1. プロジェクト概要

### 1.1 背景と目的
DIY家具・木工3D設計ソフトウェア「caDIY3D」で作成された設計データ（最新の `.cadiy4` 形式および旧バージョンの `.cadiy` 形式）を、専用デスクトップアプリをインストールすることなく、Webブラウザ上で手軽に閲覧・共有できるWebビューアを提供する。
制作したDIY作品をWebサイトやSNS、モバイル端末（iPhone/Android）上で手軽に確認できるようにし、木工・DIY愛好家間のコミュニケーションや、作業場（ガレージ・木工室など）での手元確認、部材切り出し作業を円滑にすることを目的とする。

### 1.2 システムの特徴
- **完全クライアントサイド動作 (Serverless / Static Hosting)**: バックエンドAPサーバーを一切必要とせず、GitHub Pages等の静的ホスティング環境で動作可能。
- **マルチフォーマット対応（V4 & レガシーV7形式）**: 最新の `.cadiy4`（JSON）に加え、旧バージョンの `.cadiy`（XML）ファイルを直接読み込み可能。内部でV4形式へ自動変換してシームレスに表示。
- **マルチ表示モード対応**: 「3Dview」「材料取り図（木取り図）」「三面図」をワンクリックでシームレスに切り替え。
- **インタラクティブな部材インスペクション**: 階層化されたレイヤー・オブジェクトツリーと3Dシーンが双方向同期し、各部材の規格・サイズ・重量・価格・傾き・加工情報を即座に確認可能。
- **マルチデバイス・レスポンシブ対応**: PCブラウザに加え、iPhone・iPad・Androidなどのモバイル端末での快適な表示・タッチ操作に対応。
- **多様なロード方式**: 「ローカルファイル選択」「ドラッグ＆ドロップ」「URLパラメータ指定」をサポート。

## 4. 表示モード仕様 (View Modes)

セグメントコントロールで切り替える各表示モードの要件。

### 4.1 3Dview モード (3D Perspective View)
- **概要**: 既存のリアルタイム3Dパースペクティブレンダリング。
- **特徴**:
  - OrbitControls による自由な回転（オービット）、平行移動（パン）、ズームイン/アウト。
  - 下部ツールバー（プリセット視点切替: 全体/等角/正面/上面/側面）との連動。
  - 画面左右の「詳細ビュー（プロパティインスペクタ）」および「レイヤー一覧」と完全同期。
  - 3D空間内の部材クリック（Raycasting）による直接選択に対応。

### 4.2 材料取り図 モード (Cut List View)
- **概要**: `.cadiy4` ファイル内の `cutList` データを元に、定尺材や合板などの原板から各パーツをどのように切断・木取りするかをグラフィカルに表示するモード。
- **機能要件**:
  - **切断レイアウト描画**:
    - `cutList.layouts` の配置座標 (`x`, `z`)、パーツ参照 (`partsId`)、母材 (`baseId`) を元に原板上の配置を描画。
    - 鋸刃の切り代幅（`cutList.cutWidthMm`、例: 3mm）を切断マージン・切断線として視覚化。
  - **パーツ番号・名称オーバーレイ**:
    - 切断される部材枠内にパーツ名称（天板、側板など）および寸法（mm）を表示。
  - **材料ごとのタブ / ページネーション**:
    - 複数の母材（1x4材 6フィート複数本、サブロク合板など）にまたがる場合、材料ごとにカード・図面を切り替えまたは並列表示。
  - **歩留まり・残り端材表示**:
    - 有効利用率や残った端材の長さを視認可能にする。

### 4.3 三面図 モード (Orthographic 3-View)
- **概要**: 設計図面の標準である「平面図（上面図）」「正面図」「右側図（側面図）」を同一画面上に歪みなく同時固定表示するモード。
- **機能要件**:
  - **平行投影 (Orthographic Camera)**:
    - パースペクティブ（遠近感の歪み）を排した正確な寸法比率による平行投影レンダリング。
  - **3分割同期レイアウト**:
    - 画面を3分割（または4分割枠：上面、正面、側面、アイソメ/情報）し、それぞれの固定アングル視点を同時にレンダリング。
    - パンやズーム操作を行った際、3つのビュー間でスケール（拡大縮小率）が同期する仕様。
  - **寸法線・注釈の自動表示**:
    - モデルに埋め込まれている寸法線 (`type: "dimension"`) を視認しやすいように図面調（ワイヤーフレーム＋クリーンシェーディング）で描画。

## 5. 3Dview 強化要件 (Layer Tree & Property Inspector)

### 5.1 画面左側：レイヤー一覧パネル (Layer & Object Tree)

画面左側に開閉可能なレイヤーツリーパネルを常駐表示する。

#### 5.1.1 サブフォルダを含むn段階層ツリー表示 (Hierarchical Multi-level Tree)
- **フォルダ・レイヤーの階層表現**:
  - `.cadiy4` における各レイヤーの `parentId`（親レイヤーID、ルートは `null`）に基づき、サブフォルダを含む任意深度（n段）の親子ツリー構造を構築・描画する。
  - ルートノード配下に子レイヤー（サブフォルダ）が配置され、さらにその配下に孫レイヤーがネストできる構成とする。
  - 階層レベルに応じたインデント（字下げ表示）および階層ガイドラインを適用し、ツリーの親子関係を視覚的に明瞭にする。
- **ノードの構成要素**:
  - 各レイヤーノード内には以下が階層的に包含される：
    1. 当該レイヤーを親とする**子レイヤー（サブフォルダ）**
    2. 当該レイヤー（`layerId`）に直接所属する**オブジェクト一覧（部材・パーツ等）**

#### 5.1.2 初期表示時の開閉状態 (Initial Collapse State)
- **全閉状態（Collapsed）での初期表示**:
  - ファイル読み込み完了直後の初期表示時は、すべてのレイヤーノード（親フォルダおよびサブフォルダ）のツリーを**閉じた状態（折りたたまれた状態 / collapsed）**とする。
  - 巨大なモデルや多段レイヤー構造を持つファイルであっても、一覧が縦長に肥大化せず、最上位のレイヤーのみがコンパクトに一覧表示されるようにする。
- **開閉トグル操作（アコーディオン）**:
  - 各レイヤーノードは開閉トグルアイコン（展開時: `▼`、折りたたみ時: `▶`）を持ち、クリックすることで配下の子レイヤーおよびオブジェクト一覧を展開/折りたたみできる。
  - 各階層のフォルダは独立して開閉可能とする。

#### 5.1.3 レイヤー単位の表示/非表示と初期非表示の描画抑止 (Layer Visibility & Render Suppression)
- **初期表示時の非表示レイヤー・オブジェクト描画抑止（必須要件）**:
  - ファイル読み込み時、各レイヤーの初期可視性プロパティ（`layer.visible: false`）および親レイヤーの可視性状態を厳格に評価する。
  - 初期状態で非表示に設定されているレイヤー、または親レイヤーが非表示である子孫レイヤーに所属するオブジェクト（およびオブジェクト自身で `visible === false` のもの）は、**初期シーン構築時点で3Dビュー上に一切描画しない（Three.js シーン内で非表示 `visible = false` または除外とする）**。
  - ※現状の「ファイル読み込み初期表示時に非表示設定のレイヤー所属オブジェクトが描画されてしまう」不具合を解消し、初期状態から設定通りの可視性を反映する。
- **レイヤー可視性トグル（Visibility Toggle）**:
  - レイヤー名の横に可視性トグル（チェックボックスまたは目アイコン `eye` / `eye-off`）を配置。
  - レイヤーの表示をOFFにすると、そのレイヤーおよび配下の子レイヤーに所属する全オブジェクト（部材・寸法線・テキスト等）が3Dビュー上で連動して非表示となる。
  - 再度ONにすると、オブジェクト単位の個別非表示設定を尊重しつつ再描画される。
  - 親レイヤーがOFFの場合、配下の子レイヤーも連動して非表示（あるいは親の非表示を優先）とする。

#### 5.1.4 オブジェクト選択・双方向同期
- **ツリーから選択**:
  - ツリー上のオブジェクト名をクリックすると、そのオブジェクトが「選択状態」となる。
  - 3Dシーン上の該当オブジェクトに選択ハイライト（アウトライン表示、バウンディングボックス、またはエミッシブ発光）が適用される。
- **3Dシーンから選択時の自動展開（Auto-expand）**:
  - 3Dビュー上で部材をマウスクリック（またはタップ）した際、該当オブジェクトに至る**親〜祖先レイヤーすべてを自動展開**し、左側ツリーの該当オブジェクト行までスクロールおよびハイライト選択を行う。
  - 同時に右側の「詳細ビュー」にそのプロパティが即座にバインドされる。

### 5.2 画面右側：詳細ビューパネル (Property Inspector)

オブジェクトが選択された際に、画面右側にスライドインまたは常駐表示され、選択オブジェクトの詳細属性を表示するパネル。

#### 5.2.1 表示項目一覧

| 項目グループ | 画面表示項目 | データ参照元 (`cadiy4.schema.json`) | 単位・変換・算出仕様 |
| :--- | :--- | :--- | :--- |
| **基本情報** | **名称** | `partName` および `name` | 例: `天板 (上段)`（規格名: `パイン集成材`） |
| **コスト・物性** | **規格** | `standardRef.name` または `name` | 既定の木材規格（例: `SPF 1x4材 (6F)`） |
| | **重量** | 体積 × 比重 | **算出式**: `(size.x * size.y * size.z) * specificGravity * 1000` [kg]<br>※比重（`specificGravity`）が未定義の場合は木材標準値（0.45等）を適用。 |
| | **価格** | `unitPrice` | 例: `¥650`（税込/税抜等の単価表示） |
| **幾何情報** | **位置 (X, Y, Z)** | `position.x, y, z` | **単位: mm**（内部データ m を 1000倍変換）。<br>小数点第1位まで表示。 |
| | **サイズ (X, Y, Z)** | `size.x, y, z` | **単位: mm**（内部データ m を 1000倍変換）。<br>幅 × 厚み × 長さ（例: `19 × 89 × 432 mm`）。 |
| | **傾き (Pitch, Yaw, Roll)** | `quaternion.x, y, z, w` | クォータニオンからオイラー角（Degree: 度数法 -180°〜+180°）へ変換して表示。<br>例: `X: 0°, Y: 90°, Z: 0°` |
| **加工情報** | **形状加工** | `cutAngles` / 加工メタデータ | ・斜めカット（`cutAngles`）の角度情報（例: 左端 45°カット等）<br>・ブーリアン加工・穴あけ等の加工注記 |

#### 5.2.2 閉じる・クリア操作
- パネル右上の閉じるボタン（`&times;`）または3Dシーンの背景部分をクリックすることで、選択解除および詳細ビューの折りたたみが可能。

## 6. レスポンシブ・モバイルUI要件

PCの大画面からスマートフォンの縦長画面まで対応するためのアダプティブ仕様。

1. **ヘッダ領域**:
   - PC: `[Brand]` ── `[Model Title]` ── `[Segmented Control]` ── `[Open File]` を1行横並びでゆったり表示。
   - モバイル: `[Brand]` は短縮またはアイコン化、`[Segmented Control]` はアイコン＋短縮テキスト、`[Model Title]` は省略記号（`text-overflow: ellipsis`）で収容。
2. **左右パネルの動作**:
   - **PC表示 (幅 1024px 以上)**:
     - 左右パネルはフロートまたはサイドバーとしてビューポートの邪魔をしない幅（各260px〜300px）で表示。
   - **モバイル表示 (幅 1024px 未満)**:
     - 左右パネルを初期状態では非表示（または折りたたみ）。
     - フローティングボタンまたはスワイプジェスチャーでスライドイン（ドロワー表示）。
     - 3Dビューポートの操作領域を最大化。

## 9. テスト・検証方針 (Testing & Verification)

### 9.1 大規模モデルの切り出しテストデータ運用
- **背景と課題**:
  - 実例データである `testdata/006.cadiy4` は約14MBのサイズがあり、35件のレイヤー階層、787個のオブジェクト（そのうち360個が初期非表示レイヤー所属）を含む大規模モデルである。
  - これを自動テストや日々のCIで毎回フルロードすると実行時間やメモリ使用量が増大し、開発・テストのイテレーションが低下する。
- **テスト検証要件**:
  - 要件定義完了後の実装およびテスト・検証においては、`testdata/006.cadiy4` から本要件に関連する該当構造を抽出・切り出した軽量なテスト用ファイル（例: `testdata/nested_layers_test.cadiy4`）を作成してテストを実施すること。
  - **切り出しモデルの包含要素**:
    1. **多段階層構造**: ルートレイヤー、サブフォルダ（子レイヤー）、孫レイヤーなどのn段階層構造（`parentId` の階層ネスト）。
    2. **初期非表示レイヤー**: `visible: false` の親レイヤー、子レイヤー、およびそこに所属するオブジェクト。
    3. **初期表示レイヤー**: `visible: true` の親レイヤー、子レイヤー、およびそこに所属するオブジェクト。
    4. 少数の代表オブジェクト（数個〜数十個程度）。
