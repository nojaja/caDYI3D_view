# caDIY3D Web 3Dモデルビューア 要件定義書

- **文書バージョン**: 1.0.0
- **作成日**: 2026-11-18
- **対象システム**: caDIY3D Web Viewer (仮称)

---

## 1. プロジェクト概要

### 1.1 背景と目的
DIY家具・木工3D設計ソフトウェア「caDIY3D」で作成されたモデルデータ（`.cadiy4` 形式等）を、専用デスクトップアプリをインストールすることなく、Webブラウザ上で手軽に閲覧・共有できるWeb 3Dビューアを提供する。
制作したDIY作品をWebサイトやSNS、モバイル端末（iPhone/Android）上で手軽に確認できるようにし、木工・DIY愛好家間のコミュニケーションや、作業場（ガレージ・木工室など）での手元確認を円滑にすることを目的とする。

### 1.2 システムの特徴
- **完全クライアントサイド動作 (Serverless / Static Hosting)**: バックエンドAPサーバーを一切必要とせず、GitHub Pages等の静的ホスティング環境で動作可能。
- **マルチデバイス・レスポンシブ対応**: PCブラウザに加え、iPhone・iPad・Androidなどのモバイル端末での快適な表示・タッチ操作に対応。
- **多様なロード方式**: 「ローカルファイル選択」「ドラッグ＆ドロップ」「URLパラメータ指定」の3系統をサポート。
- **TypeScript + Vite による高速・堅牢なビルド**: 型安全性と最適化された静的モジュールバンドル。

## 3. 入力データ仕様

### 3.1 主対象フォーマット
- **拡張子**: `.cadiy4`
- **形式**: JSONフォーマット（UTF-8）
- **仕様準拠**: `docs/spec/cadiy4format/cadiy4.schema.json`
- **構成要素**:
  - メタ情報・カメラ情報 (`version`, `thumbnail`, `camera.position`, `camera.target`)
  - 部材オブジェクト (`objects[*]`: 角材, 板材, 丸棒, 円形板, 寸法線, 注釈, 既製パーツなど)
  - 階層レイヤー (`layers[*]`)
  - 木取り図データ (`cutList`)

### 3.2 将来拡張フォーマット（検討）
- 汎用3Dモデル形式（glTF / GLB, OBJ, STL 等）へのプラグイン対応の余地を残した設計とする。

## 4. 機能要件

### 4.1 モデル入力・ロード機能 (FR-01)

| ID | 機能名 | 要件詳細 |
| :--- | :--- | :--- |
| **FR-01-01** | **ファイルピッカー選択** | 画面上の「ファイルを選択」ボタンまたはUIエリアをクリックし、OS標準のファイルダイアログから `.cadiy4` ファイルを選択して即座に3D描画する。 |
| **FR-01-02** | **ドラッグ＆ドロップ (D&D)** | ブラウザウィンドウ全体またはビューポート上にファイルをドラッグ＆ドロップすることで、直接ロードを行う。 |
| **FR-01-03** | **URLパラメータロード** | クエリパラメータ `?model=<URL>` または `?url=<URL>` を指定してアクセスした場合、指定された外部/同一ホスト上のURLからファイルを自動フェッチして表示する。<br>*(例: `https://<user>.github.io/caDYI3D_view/?model=testdata/001.cadiy4`)* |
| **FR-01-04** | **デモ／サンプルモデル切替** | 初回訪問時やモデル未指定時向けに、ワンクリックで開けるサンプルモデル（`testdata`配下など）のクイック選択機能を提供する。 |
| **FR-01-05** | **ロード進捗・エラー表示** | 読み込み中インジケータ（スピナー）の表示、ファイル形式の構文エラーやネットワークエラー（CORS制限、404等）の適切なユーザー通知。 |

### 4.2 3Dシーン描画機能 (FR-02)

| ID | 機能名 | 要件詳細 |
| :--- | :--- | :--- |
| **FR-02-01** | **基本形状のプロシージャル生成** | `.cadiy4` のオブジェクト定義に基づき、3Dメッシュを生成・配置する。<br>・`lumber` (角材): 直方体 + 斜めカット（`cutAngles`）対応<br>・`board` (板材): 板厚・幅・長さの直方体 + カット対応<br>・`cylinder` / `roundBoard`: 円柱・円形板メッシュ |
| **FR-02-02** | **姿勢・座標の忠実な再現** | 各パーツのワールド座標 (`position`)、四元数回転 (`quaternion`)、スケール (`size`) を正確に適用する。 |
| **FR-02-03** | **マテリアル・テクスチャ** | パーツ固有の色 (`color.r, g, b`)、木目テクスチャ (`textureId`)、木材らしい質感（陰影・ラフネス）を表現する。 |
| **FR-02-04** | **寸法線・注釈の描画** | `type: "dimension"`（寸法線、矢印、寸法値テキスト）および `type: "comment"` などの注釈要素を3D空間上またはオーバーレイとして表示する（表示/非表示切替可能）。 |
| **FR-02-05** | **初期カメラ同期** | ファイル内の `camera.position` および `camera.target` に基づき、ロード時に制作者が意図した視点でカメラを初期配置する。 |
| **FR-02-06** | **環境光・影・グリッド** | モデルの立体感を高めるライティング（ディレクショナルライト + アンビエントライト）、地面グリッド／作業台基準面の表示。 |

### 4.3 ビューポート操作・カメラ制御 (FR-03)

| ID | 機能名 | 要件詳細 |
| :--- | :--- | :--- |
| **FR-03-01** | **PC操作 (マウス/キーボード)** | ・左ドラッグ: 回転（オービット）<br>・右ドラッグ / 中ドラッグ: パン（平行移動）<br>・ホイールスクロール: ズームイン / ズームアウト |
| **FR-03-02** | **モバイル操作 (タッチ)** | ・1本指ドラッグ: 回転<br>・2本指ドラッグ: パン<br>・ピンチイン/ピンチアウト: ズームイン / ズームアウト<br>・画面回転（縦向き・横向き）への追従 |
| **FR-03-03** | **カメラコントロールUI** | ・全体表示（モデル全体が収まるように視点を自動調整する「Fit to View」ボタン）<br>・初期視点リセットボタン<br>・プリセット視点切替（正面/上面/右側面/等角投影アイソメ） |

### 4.4 UI・レスポンシブ対応 (FR-04)

| ID | 機能名 | 要件詳細 |
| :--- | :--- | :--- |
| **FR-04-01** | **レスポンシブレイアウト** | PCの大画面からスマートフォンの縦長・狭小画面まで破綻しないレスポンシブUI。<br>モバイル表示時は3Dビューを最大化し、操作メニュー類は折りたたみ式ドロワーまたはフローティングボタンとする。 |
| **FR-04-02** | **全画面表示 (Fullscreen)** | モバイルおよびPCでの全画面表示切り替え機能（Web Fullscreen API）。 |
| **FR-04-03** | **パーツ情報表示 (インスペクタ)** | 3Dモデル上のパーツをタップ/クリックした際に、パーツ名・規格名・寸法（厚×幅×長）・単価等の詳細情報をポップアップ/サイドバーで表示する。 |
| **FR-04-04** | **レイヤー/パーツツリー表示** | レイヤーごとの表示/非表示切り替えチェックボックス。 |

## 5. 非機能要件

### 5.1 アーキテクチャ・ホスティング
- **完全静的配信**: 静的HTML/CSS/JSファイルのみで完結。Webサーバー側に特別なランタイムやAPIは不要。
- **GitHub Pages 互換性**: 相対パス対応（リポジトリ名サブディレクトリ配下でも、ルートドメインでも動作する Vite の `base` 相対設定 `./`）。
- **CORS制約考慮**: 外部URLからモデルをロードする際、外部ホスト側でCORSヘッダー（`Access-Control-Allow-Origin: *`）が許可されている必要がある旨のUIアナウンス・ガイドを整備。

### 5.2 パフォーマンス・リソース要件
- **初期バンドルサイズ**: 初期ロード速度向上のため、総転送サイズを可能な限り圧縮（gzip後 500KB〜1MB程度を目標）。
- **描画パフォーマンス**: iPhone SE等の普及帯スマートフォンでも常時 60fps 近傍を維持できるよう、ドローコールの最適化およびジオメトリ共有を行う。
- **メモリ管理**: モデル再読み込み時に前回のジオメトリ・マテリアル・テクスチャの `dispose()` を確実に実行し、ブラウザのメモリリークを防止する。

### 5.3 セキュリティ
- **クライアントサイドパースの安全性**: アップロードされたJSONを直接 `JSON.parse` する際の例外捕捉と、Zod / スキーマバリデーションによる不正データのブロック。
- **XSS防止**: ファイル内の文字列（パーツ名、コメント等）をHTMLにレンダリングする際の完全エスケープ処理。

## 6. 開発・ビルドパイプライン要件

1. **パッケージマネージャ**: `npm` または `pnpm`
2. **言語**: `TypeScript 5.x`
3. **バンドラー**: `Vite 5.x / 6.x`
4. **成果物構成**:
   ```
   dist/
   ├── index.html
   ├── favicon.ico
   ├── assets/
   │   ├── index-[hash].js
   │   └── index-[hash].css
   └── testdata/ (動作検証用サンプルデータ)
   ```
5. **CI/CD**: GitHub Actionsワークフロー（`.github/workflows/deploy.yml`）により、`main` ブランチへのプッシュ時に自動ビルドして GitHub Pages (`gh-pages` 環境) へデプロイ。
